# Sonsuz Döngüdeki Kedi Miyavlayıcı

## Bu Ne Lan?

Bu proje, evrenin en büyük gizemini çözmeyi amaçlamaktadır: Bir kedi, kutunun içinde miyavlar mı, miyavlamaz mı? Yoksa hem miyavlar hem miyavlamaz mı?

**Ciddi bir bilimsel araçtır.** NASA bile bunu kullanıyor olabilir. Belki de kullanmıyordur. Bilemeyiz.

### Nasıl Çalışır?

```bash
python kedi.py
```

Kod sonsuz döngüde çalışır. Ctrl+C ile kurtulabilirsiniz. Belki. Kedi izin verirse.

### Özellikler

- %50 ihtimalle miyav
- %50 ihtimalle ölü kedi (sessizlik)
- Kuantum belirsizliği
- Türkçe felsefi yorumlar
- Gerçekten çalışır (test edildi, kedi kızdı)

## Katkıda Bulunma

Lütfen katkıda bulunmayın. Kedi kızar.
